# SMBIN — PLATAFORMA MAESTRA DEFINITIVA
**Director:** Miguel Rojas Panduro  
**Ámbito:** Loreto (9 Provincias), Lima / Nacional, El Mundo, SMBIN TV 24/7.  

## Características Principales:
1. **Diseño Simétrico 50/50:** Portada Principal (izquierda) y SMBIN TV 24/7 (derecha) exactamente del mismo tamaño.
2. **Menú Completo:** Portada, Loreto, Lima, El Mundo, SMBIN TV, Vídeos (30 días de archivo) y Contactos (datos del diario y periodistas).
3. **CMS Privado para Periodistas:** Fuentes internas, edición y borrado de noticias restringidos exclusivamente al periodista autenticado; el público no ve información confidencial.
